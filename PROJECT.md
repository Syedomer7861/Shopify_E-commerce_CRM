# CureForever CRM

**Shopify + Shiprocket Customer Follow-up CRM**
Built for high-fidelity order tracking, automated WhatsApp engagement, and proactive transit management.

## Project Identity
- **Stack**: Next.js 14, Supabase, Tailwind CSS, Meta WhatsApp Cloud API.
- **Authority**: Shopify is the primary source of truth for orders and customer data.
- **Logistics**: Shiprocket provides real-time delivery events.

## System Architecture

### 1. Data Layer (Supabase)
- **Orders**: Synchronized from Shopify, enriched with Shiprocket tracking data.
- **Customers**: Segmented by purchase behavior (1-time, Repeat, Inactive) and health (RTO risks).
- **Tasks**: Event-driven follow-ups generated by delivery status.
- **Workflows**: Stateful automation chains for engagement.

### 2. Integration Layer
- **Shopify Webhooks**: `orders/create`, `orders/fulfilled`.
- **Shiprocket Webhooks**: `delivered`, `out_for_delivery`, `rto`, `failed`.
- **WhatsApp Bridge**: local Node.js server (`wa_server.js`) and Meta Cloud API integration.

### 3. Logic Layer (Workflow Engine)
- Trigger-based automations based on delivery lifecycle.
- Sentiment-aware review collection (skips if there's an active issue).
- Inventory-aware re-order campaigns.

## Core Values
- **High Fidelity**: 1:1 data parity between Shopify and the CRM.
- **Proactive**: Notification of transit issues before the customer complains.
- **Automation First**: Manual tasks only when human touch is strictly required.
