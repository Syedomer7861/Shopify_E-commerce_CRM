# CureForever CRM — Ultimate User & System Guide

Welcome to the **CureForever CRM**, a production-grade, high-fidelity operations suite designed specifically for advanced Shopify and Shiprocket ecosystems. This guide outlines the system architecture, module flows, and role-based responsibilities to ensure a seamless onboarding experience.

## 1. System Philosophy & Architecture
The CureForever CRM acts as the "Central Nervous System" for your e-commerce operations. It bridges the gap between customer orders, shipping logistics, and personnel management.

- **Data Sync:** Real-time synchronization with Shopify (Orders/Carts) and Shiprocket (Tracking Status).
- **Automation First:** Automated task generation for abandoned carts and delayed shipments.
- **Unified HR:** A complete suite for managing the people who run the business.

## 2. Role-Based Access Control (RBAC)

### 👤 Admin (Full Access)
- **Oversight:** Real-time monitoring of all agent activities and revenue streams.
- **Personnel:** Full management of the HR Suite (Payroll, Attendance, Policy setting).
- **Strategy:** Access to high-level analytics, ROI reports, and workflow automation settings.
- **Hardening:** System-wide configuration and audit logging.

### 🎧 Agent (Operational Access)
- **Execution:** Resolving assigned recovery tasks and customer inquiries.
- **Communication:** Sending WhatsApp messages and logging call outcomes.
- **Personal:** Viewing their own attendance, payslips, and training assignments.
- **Data Entry:** Updating customer profiles and order notes.

## 3. Core Module Workflows

### 📦 Orders & Shipments
**Flow:** `Shopify Sync` → `CRM Order Grid` → `Shiprocket Tracking` → `Automated Status Updates`
- **Features:** Unified view of orders from multiple sources, real-time status badges (In Transit, Delivered, RTO), and direct links to Shopify/Shiprocket dashboards.
- **Best Practice:** Use filters to identify "In Transit" orders that have been stuck for more than 3 days to proactively contact customers.

### 🛒 Abandoned Cart Recovery
**Flow:** `Abandoned Checkout` → `Automatic Task Creation` → `Agent Assignment` → `WhatsApp Follow-up` → `Conversion`
- **Features:** Real-time task injection, conversion tracking, and "Copy Link" for easy sharing with customers.
- **Priority Scoring:** High-value carts are automatically prioritized for immediate agent attention.

### 📋 Task Management
**Flow:** `Task Trigger` → `Agent Action` → `Outcome Logging` → `Task Resolution`
- **Types:** Recovery, Review, Reorder, and General follow-ups.
- **Outcomes:** Agents must log every call (Done, Busy, Wrong Number, WhatsApp Sent) to maintain a clean audit trail.

### 👥 HR Management Suite
**Flow:** `Onboarding` → `Daily Attendance` → `Performance Review` → `Payroll Generation`
- **Attendance:** Real-time monthly grid for marking presence, leaves, and holidays.
- **Payroll:** Automated calculation based on Indian tax slabs (PF, PT, TDS) with digital payslip generation.
- **Engagement:** Handling grievances, training modules, and performance scoring.
- **Documents:** Instant generation of Offer Letters, Relieving Letters, and Warning Letters.

### 💬 WhatsApp Communication
**Flow:** `Select Customer` → `Choose Preset/Manual` → `Send via Cloud API` → `Log Notification`
- **Features:** Preset message library for standard responses, manual drafting, and real-time delivery status.
- **Admin Visibility:** Every WhatsApp sent is logged in the Admin notification stream.

## 4. Step-by-Step Journeys

### A. For the Admin: "The Morning Routine"
1. **Dashboard Check:** Review the "Revenue Recovered" vs "Revenue at Risk" cards.
2. **Notification Stream:** Scan the latest agent actions to ensure team alignment.
3. **Attendance:** Open the **Attendance Register** to verify the floor presence.
4. **Leaderboard:** Check the performance metrics to identify top-performing agents for the day.

### B. For the Agent: "The Productivity Loop"
1. **Tasks Tab:** Start with "Priority 1" Abandoned Cart tasks.
2. **Action:** Click the Phone icon to call or the WhatsApp icon to send a recovery link.
3. **Log:** Immediately select the "Outcome" to move the task to the next stage.
4. **Profile:** Update any new customer details (Phone/Address) discovered during the call.

## 5. Troubleshooting & Best Practices

- **Sync Delay:** If a new Shopify order isn't visible, click the "Sync" button in the Orders module or check the Webhook status in Settings.
- **Data Integrity:** Never delete records manually; use the "Offboard" or "Archive" features to preserve the audit trail.
- **Security:** Always log out at the end of the shift. All administrative operations are gated by role checks and IP logging.
