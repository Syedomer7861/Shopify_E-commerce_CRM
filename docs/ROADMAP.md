# Project Roadmap

Project roadmap for CureForever CRM. Each phase builds towards higher automation and better data fidelity.

---

## Milestone 1: Core Foundation & Sync (100% COMPLETE)

### ✅ Phase 1: Infrastructure & Data Sync
- Supabase schema definition.
- Shopify bulk historical sync.
- Shopify lifecycle webhooks integration.
- Shiprocket delivery status mapping.
- Basic task generation for delivered orders.

### ✅ Phase 2: Agent Interface & Profiles
- Dashboard with daily call lists.
- Customer profile views with order history.
- Task management (complete, reschedule, skip).
- Basic order tracking visibility.

### ✅ Phase 3: Advanced Business Logic
- Product-specific review timing overrides.
- Customer segmentation (Repeat, Inactive, Risky).
- Bulk Excel import for legacy data.
- Settings panel for automation toggles.

---

## Milestone 2: Intelligent Automation & Hardening (100% COMPLETE)

### ✅ Phase 4: Workflow Hardening & Advanced Automation
- **Goal**: Hardening sync engine and expanding follow-up workflows.
- **Features**:
  - ✅ **Shopify OAuth Auto-Refresh**: Zero-touch persistent API connectivity.
  - ✅ **Fastrr Checkout Sync**: Real-time abandoned cart capture via webhooks.
  - ✅ **Smart Task Assignment**: Workload-aware distribution for agents.
  - ✅ **Transit Inform Pipeline**: Proactive notifications for stale shipments.

### 🚀 Phase 5: Deep Intelligence & Reporting
- **Goal**: ROI tracking and AI-assisted engagement.
- **Features**:
  - [ ] Campaign Performance Tracking (linking follow-ups to revenue).
  - [ ] Analytics Export (XLSX reports for calls and revenue).
  - [ ] Retention Heatmaps.

---

## Milestone 3: Scale & Omnichannel

### 🔜 Phase 6: Omnichannel Presence
- **Goal**: Expand beyond WhatsApp and Web.
- **Features**:
  - [ ] Click-to-call integration (Cloud Telephony).
  - [ ] SMS fallback for WhatsApp failures.
  - [ ] Calendar view for scheduled follow-ups.
