# Courier Performance Audit

## Description
A dashboard section comparing delivery success rates across different Shiprocket couriers (e.g., Delhivery vs. BlueDart) to optimize shipping choices.

## Requirements
- Aggregate delivery data by courier name from the database.
- Calculate success rate (Delivered / Total) per courier.
- Visualize performance in a chart on the Admin Dashboard.
