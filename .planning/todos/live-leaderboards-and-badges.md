# Live Leaderboards and Badges

## Description
A competitive leaderboard for agents showing "Recovery Value" and "Tasks Resolved" in real-time, plus a badge system for performance milestones.

## Requirements
- Real-time aggregation of recovery revenue per agent.
- Dashboard component for the leaderboard.
- Logic to award badges (e.g., "NDR Ninja") based on metrics.
